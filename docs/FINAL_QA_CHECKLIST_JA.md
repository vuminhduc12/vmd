# 最終QAチェックリスト（10〜20人運用向け）

最終更新: 2026-04-18  
対象: BOXER PRO（iPhone PWA + Web）

## 0. 事前準備

- [ ] 本番URLでアクセスできる（HTTPS）
- [ ] iPhoneにホーム画面追加済み（PWA）
- [ ] `マイ設定 > 保存先ステータス` が確認できる
- [ ] Supabaseログイン可能
- [ ] テスト用ユーザーを2つ用意（`tester-a`, `tester-b`）

---

## 1. iPhone PWA: 新規保存→即表示更新→日付跨ぎ

### 1-1. 新規保存の即時反映
- [ ] 体重を1件保存 → ダッシュボードKPIに即反映
- [ ] 食事を1件保存 → 本日のkcal/PFCに即反映
- [ ] 練習を1件保存 → 本日の練習時間・消費kcalに即反映
- [ ] 水分/回復を保存 → カロリー画面とダッシュボードに反映

期待結果:
- 保存後3秒以内に表示更新される
- 保存成功トーストと実データ表示が一致する

### 1-2. 日付跨ぎ
- [ ] アプリを開いたまま日付を跨ぐ（または端末日付変更で疑似再現）
- [ ] 30秒以内、またはアプリ復帰時に「当日表示」へ切替

期待結果:
- 前日データが「本日KPI」に残らない
- 本日未入力なら `--` / `0` 系表示になる

---

## 2. ローカル/クラウド切替時の見え方

- [ ] Supabaseログイン状態で保存（クラウド）
- [ ] ログアウトしてローカル保存状態を確認
- [ ] 再ログインしてクラウドデータに戻ることを確認
- [ ] `この端末のデータをクラウドへマージ` 後の重複/欠落確認

期待結果:
- 保存先バッジ表示と実データが一致する
- 切替後に「消えたように見える」だけでなく、データ整合が取れている

---

## 3. 画像アップロード（体重/対戦相手）

### 3-1. 体重写真
- [ ] 体重記録に写真1〜3枚アップロード
- [ ] 一覧/詳細で表示確認
- [ ] 1枚削除、全削除、再アップロード確認

### 3-2. 対戦相手写真
- [ ] 新規相手に写真登録
- [ ] 編集で写真差し替え
- [ ] 相手削除時に写真参照が残らないこと

期待結果:
- 画像が壊れず表示される
- 削除後に幽霊サムネイルが残らない

---

## 4. AIチャットのレート制限（429）

- [ ] 同一ユーザーで短時間に連続実行し、`429` が返ることを確認
- [ ] `Retry-After` ヘッダー相当の待機後に再実行して復帰すること
- [ ] 管理API（admin stats）でも制限が効くこと

期待結果:
- 制限超過時に静かに失敗せず、UIで判別できる
- 待機後は正常復帰する

---

## 5. 合格判定（リリース可否）

- [ ] P0（データ消失、保存不能、画面操作不能）が0件
- [ ] P1（主要機能の継続利用を妨げる不具合）が0件
- [ ] P2以下のみ残件化（期限付き）

リリース可否:
- [ ] Go
- [ ] No-Go
